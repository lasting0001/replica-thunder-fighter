## 3. 性能数据

- 战斗平均帧率：**60.5 fps**（2 秒采样，960×632 窗口）
- 画布：逻辑 720×1280，DPR 上限 2；测试环境 DPR=1
- 实体规模：粒子上限 240/380/520（随画质），玩家子弹池 160、敌弹池 240
- 观察项：小窗口下（CSS 宽 356）画布仍按 720 逻辑宽渲染，像素比约 2.02，属固定逻辑分辨率设计，未做降采样。

## 5. 遗留风险

1. 未在真实手机（iOS/Android）上验证触屏手感、刘海安全区与横屏旋转提示，仅完成 CSS 与桌面模拟检查。

3. `file://` 下 `localStorage` 依赖浏览器策略；Chrome/Edge 正常，其他浏览器未逐一验证。
4. BGM 与音效未做听力验收（仅确认运行、静音与音量分轨生效）。
