## 2. 核心循环

```
选择战机/装备 → 进入关卡（消耗体力） → 自动射击 + 拖动走位
   → 击毁敌机/拾取道具（水晶、武器升级、护盾、回血、暴走）
   → 遭遇 BOSS（多管血、多阶段弹幕） → 战斗胜利/坠毁
   → 结算（分数、掉落残骸/材料） → 回仓库强化装备/进阶
   → 战力提升 → 挑战下一关
```

关键判断：

- 操作门槛极低：**自动开火**，玩家只负责走位与拾取；难度来自弹幕密度而非操作复杂度（B）。
- 命中判定为战机中心的**小闪光点**，而非整机碰撞盒；这决定了“擦弹走位”的手感（B/C）。
- 单局节奏：小怪波次（约 30–45 秒）→ BOSS（约 15–25 秒），每关 1–2 分钟（C/D）。
- 战力数值门控：关卡标注敌方战力，低于推荐值仍可强制挑战，但会被数值压制（B）。

## 4. 模式与关卡

### 4.1 闯关模式（星际征战）

- 剧情：人类因“希望水晶”分裂为**地球联邦**与**行星同盟（星盟）**，玩家扮演联邦战机驾驶员，跨越**十二星座**作战。
- 规模：首发约 **80 个关卡**、**20 个 BOSS**；每章对应一个星座，章末有守护机甲（B）。
- 结构：白羊座 1–8 关、金牛座 9–16 关，以此类推（C）。
- 前 3 关为教学关（副驾驶莉莎），无 BOSS、不扣血；第 4 关起为正式关卡并出现 BOSS（C）。
- 关卡标注“敌方战力”，例如第 1 关 360、第 4 关 720、第 8 关 1116（C）。

### 4.2 无尽模式

- 从低级敌机开始无限刷新，杂兵战与 BOSS 战交替，十二宫守卫轮番上阵。
- 与好友比分数，周榜奖励；每次消耗 1 点体力（B）。

### 4.3 BOSS 模式 / 空间站（更新后加入）

- 天马座、白鸟座、天龙座、仙女座等空间站，用于刷装备（A）。
- 本复刻 Demo 不纳入。

## 6. 美术风格与色板

- 总体：高饱和、强对比的太空科幻；深蓝黑背景 + 青蓝色玩家方 + 红橙色敌方 + 黄绿色道具。
- 场景：地球/卫星/空间站/域外星系，带星云、星球弧线、陨石；弹幕高亮发光。
- 玩家战机：白蓝机体、青色能量线、中心亮点；不同系列有不同主色（突击蓝白、尖峰青、凤凰橙红、幻影紫、异形黑金）。
- 敌方：星盟机型以红、橙、紫、钢灰为主，轮廓粗犷。
- 道具：绿色宝石（分数）、黄色箭头（武器升级）、黄色 S（暴走）、绿色加号（回血）、蓝色六边形（护盾）。

## 8. 操作与数值（观测/推断）

### 8.1 操作

- 触屏：在屏幕任意位置按下并拖动，战机按手指位移相对移动（相对拖拽，不是“飞机瞬移到手指”）。
- 键盘（复刻版新增）：方向键/WASD 移动，空格必杀，P/Esc 暂停。
- 必杀：屏幕左下角圆形按钮，点击立即释放。
- 自动开火：无需按键。

### 8.2 可测数值

| 项目 | 观测/推断 | 依据 |
|---|---|---|

## 9. 难度曲线（2014 首发）

- 第 1–3 关：教学，无 BOSS，不掉血，建立操作与道具认知。
- 第 4 关：首个 BOSS，3 管血，散弹为主，20 秒内可解决。
- 第 5–8 关：大敌机增多，出现护盾与 S 符文，章末 BOSS「布莱特」需打两次形态。
- 第 9 关起（金牛座）：中型机双列、曲线自杀机、BOSS 多弹道叠加。
- 中后期：蓝色覆盖型弹幕 + 红色速射弹组合，必须依赖走位与暴走/护盾。
- 复刻 Demo 取“第 4 关”难度：4 波杂兵 + 1 个三阶段 BOSS，用于验证手感。

## 10. 已知差异点 / 版本陷阱

1. **《雷霆战机2》≠ 腾讯《雷霆战机》**：前者是单机前身（12 关、每关 BOSS），后者是腾讯发行的手游（80 关、十二星座、装备养成）。本复刻取后者。
2. 2015 年后加入战神合体、驾驶员、BOSS 模式、精英无尽等，均不属于 2014 首发形态，Demo 不做。
3. 不同渠道对“初始战机”的描述不一（雷电1号/突击零式）；以官方 2014 文章为准：**突击零式**。
4. 首个 BOSS 名称在不同玩法中为「红色重装机 / 重装红色机 / 赤色之狼」，本复刻使用「红色重装机」。

## 12. 结论

2014 版《雷霆战机》的可复刻核心是：**自动开火 + 相对拖拽 + 小判定点 + 四段火力 + 暴走 + 清屏必杀 + 多管血 BOSS**。这套闭环足以支撑一个 60–90 秒的高密度竖版弹幕 Demo；装备养成与关卡地图属于周边系统，放在里程碑 M2。当前资料足以进入规格化与 Demo 阶段，所有精确数值按第 8 节推断表执行，并在 Demo 验收时依据用户手感反馈回填。
