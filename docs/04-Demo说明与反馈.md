## 1. Demo 范围

只验证“像不像、跟不跟手”，不做完整内容。

**已实现**

- 完整闭环：标题 → 战斗 → 胜利/失败结算 → 再战/返回标题。
- 相对拖拽移动 + 键盘移动；自动开火。
- 中心小判定点、受击无敌闪烁、装甲血条。
- 火力 1–4 级（2/3/4/5 路弹道），满级后拾取触发暴走。
- 暴走：伤害 ×1.6、射速 ×1.6、得分 ×2、持续 6 秒。
- 必杀：2 发，清屏、全屏 140 伤害、1.6 秒无敌。
- 道具：水晶、武器升级、S 暴走、回血、量子护盾（吸收 4 发/8 秒）。
- 三类杂兵（小型机、中型机、自杀机）与 18 波脚本化编队。
- BOSS「红色重装机」：3 管血、3 阶段、扇形/瞄准连射/环形/炮口副射。
- 拾取、爆炸、震屏、受伤红晕、开场横幅、WARNING、结算统计。
- WebAudio 合成音效 + 静音开关；桌面/触屏自适应；最高分本地存储。

**未实现（按计划留给 M2/M3）**

- 主界面机库、仓库/强化/进阶、星座闯关地图、体力、无尽模式、BOSS 模式、排行。
- 正式美术与音乐、多关卡、多种 BOSS、背景剧情、设置页、存档结构。

## 2. 运行方式

- 直接双击 `demo/index.html`（`file://` 下音效与最高分存储均可用）。
- 或本地起服务：`python -m http.server 8123`，访问 `http://localhost:8123/demo/index.html`。
- 推荐竖屏窗口；桌面可用鼠标拖动。

| 规格项 | Demo 实现 | 说明 |

| BOSS 弹幕 | 扇形/瞄准/环形 + 炮口副射 | 略简化，未做激光扫射与召唤小怪 |

## 5. 自检记录

| 检查项 | 方式 | 结果 |
|---|---|---|
| JS 语法 | `node --check` | 通过 |

| 修复回归 | 死亡瞬间清空敌弹导致的 `TypeError` | 已修复并复测通过 |
| BOSS 出现/血条/弹幕 | Chromium 实机（存活至 43 秒） | 通过 |
| 60fps | 未做专业采样 | 待 M3 用 Performance 面板确认 |

**已知限制**

1. 静止不动约 10–15 秒会被击落；需要走位才能见到 BOSS。
2. BOSS 战未做“击破后剩余弹幕渐隐”，击破瞬间直接清空。
3. 手机端首次点击才解锁音频（浏览器策略）。
4. 暂停时不响应窗口尺寸变化的重新布局（画布为等比缩放，实际影响很小）。

## 6. 试玩指引（3 条）

1. 先沿屏幕下方左右移动，吃黄色箭头把火力升到 LV4，再吃第 4 个触发暴走，观察弹道与得分变化。
2. 被弹幕包围时按左下“必杀”，确认清屏、全屏伤害与短暂无敌。
3. 坚持到 41 秒后的 BOSS，观察三管血与阶段变化，尝试在扇形弹幕的缝隙中穿行。
