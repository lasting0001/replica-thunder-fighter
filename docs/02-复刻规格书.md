# 02 复刻规格书：雷霆战机（2014 初代经典版）

> 配套文档：`01-调研报告.md`。本文所有数值均为可直接编码的确定性规格；标 `D` 的为推断值，验收后回填。

## 1. 技术方案

- 零依赖单页：原生 HTML + CSS + Canvas 2D + WebAudio，`index.html` 双击可打开，无需构建。
- 逻辑分辨率：**720 × 1280（9:16）**，CSS 等比缩放适配视口；DPR 上限 2。
- 渲染：`requestAnimationFrame` + 固定步长 **1/60s**，最多补 5 步；逻辑与渲染分离。
- 输入：Pointer Events（鼠标/触屏统一）+ 键盘；相对拖拽。
- 状态：单一 `mode` 全局状态机，实体数组驱动；所有手感参数集中在 `CFG` 对象。

## 2. 全局状态机

```
title ──点击开始──> playing ──暂停──> paused ──继续──> playing
  ↑                    │                  │
  │                    ├──玩家 HP≤0──> defeat ──再战──> playing
  │                    └──BOSS 击破──> victory ──再战──> playing
  └──────────────── 返回标题 ────────────────────────────┘
```

| 状态 | 进入条件 | 行为 | 退出 |
|---|---|---|---|
| title | 启动 / 返回标题 | 星空滚动、展示机、最高分 | 点击“开始出击” |
| playing | 开始/重开 | 更新全部实体与脚本 | 暂停/坠毁/胜利 |
| paused | P/Esc/暂停按钮 | 冻结 update，保留渲染 | 继续/重开/返回 |
| victory | BOSS 血条清零 | 延迟 2.2s 弹结算 | 再战/返回 |
| defeat | 玩家 HP≤0 | 延迟 1.7s 弹结算 | 再战/返回 |

### 2.1 玩法子状态

- 玩家：`alive / invincible / shield / normal`；死亡后 `alive=false`，停止开火与受击。
- 武器：`power=0..3`（显示 LV1–LV4）；`power=3` 时拾取武器 → 暴走。
- 暴走：`rage>0` 为激活，倒计时结束回到普通。
- BOSS：`entering → phase0/1/2 → destroyed`；每管血对应一个阶段。

## 12. 验收口径（Demo）

1. 开始 → 战斗 → 结算 → 重开完整闭环，无阻断。
2. 相对拖拽不跳变，命中仅判定中心点。
3. 火力 4 级可达成，满级后再拾取进入暴走并有明显增益。
4. 必杀可清弹、造成全屏伤害、短暂无敌。
5. BOSS 三管血三阶段，破管与击破均有反馈。
6. 60fps 稳定，桌面与手机触屏均可操作。
