# 雷霆战机 · H5 复刻（Thunder Fighter Replica）

竖版弹幕射击游戏的 H5 复刻，对象为 2014 年腾讯发行的《雷霆战机》初代形态。原生 HTML + CSS + Canvas 2D + WebAudio，**零依赖、无需构建、双击即玩、无任何网络请求**。

> **声明**：本项目仅用于个人学习与技术研究，不商用、不公开发布原作资产。所有美术均为 Canvas 程序化绘制，所有音效与 BGM 均由 WebAudio 合成，未使用原作的图片、音频、字体或代码，也不包含任何商标与版权标识。

---

## 快速开始

```bash
# 方式一：直接双击
index.html

# 方式二：本地静态服务器（推荐，避免个别浏览器对 file:// 的存档限制）
python -m http.server 8000
# 然后访问 http://localhost:8000
```

推荐 Chrome / Edge。首次点击后才会创建 `AudioContext` 播放声音（浏览器自动播放策略）。

## 操作

| 操作 | 键鼠 / 触屏 |
|---|---|
| 移动 | 任意位置按下并拖动（1:1 相对拖拽，战机不瞬移）/ 方向键、WASD |
| 射击 | 自动开火，无需按键 |
| 必杀 | 左下角圆形按钮 / 空格（全屏伤害 + 清弹 + 短暂无敌） |
| 暂停 | 右下角按钮 / P、Esc |
| 静音 | 右上角按钮 |

命中判定仅为战机中心的 5px 亮点，走位擦弹是核心玩法。

## 玩法与内容

- **星际征战**：白羊座、金牛座两章共 16 关，数据表驱动，可继续扩展章节。前 3 关为教学关，第 4 / 8 / 12 / 16 关为 BOSS 关（3 管血 3 阶段）。
- **无尽挑战**：动态波次，强度随波数递增，每 5 波出现守卫 BOSS，记录最高波与最高分。
- **3 架战机**：突击零式（普通弹道）、尖峰零式（贯穿）、猎鹰零式（范围），弹道、配色与数值各异。
- **3 种 BOSS**：红色重装机（扇形 / 点射 / 环形 + 侧翼炮）、布莱特（高速点射 / 交叉扇面 / 反向环）、金牛座守卫（旋转螺旋 / 双层环 / 召唤僚机）。
- **火力成长**：拾取黄色箭头升级 LV1–LV4；满级后再拾取进入**暴走**（6 秒，伤害/攻速提升、得分 ×2、击杀清弹）。
- **道具**：水晶（分数）、武器升级、暴走 S、生命恢复、量子护盾（吸收 4 发）。
- **仓库养成**：残骸强化（每级 +2% 攻击/生命）、满级进阶（最多 3 星，每星 +12%），战力实时作用于战斗。
- **系统**：主界面、星图、仓库、设置（音乐/音效分轨、静音、画质、清档）、暂停、结算、`localStorage` 存档（损坏自动回退默认值）。

## 技术要点

| 项 | 方案 |
|---|---|
| 渲染 | Canvas 2D，逻辑分辨率 720×1280（9:16），CSS 等比缩放，DPR 上限 2 |
| 循环 | `requestAnimationFrame` + 固定步长 1/60s，最多补 5 步，逻辑与渲染分离 |
| 输入 | Pointer Events（鼠标/触屏统一）+ 键盘，相对拖拽 |
| 音频 | WebAudio 振荡器与噪声合成 11 种音效 + 2 首程序化 BGM |
| 架构 | 经典 `<script>` 顺序加载，全局状态机 + 实体数组，手感参数集中在 `CFG` |
| 性能 | 子弹/敌弹/粒子对象池，粒子上限按画质缩放（240 / 380 / 520），实测约 60.5 fps |


## 已知限制

- 关卡为数据生成，尚未逐关手工调难度；第 4 关起需要主动走位规避。
- 无尽模式数值按线性缩放，超长局内容会重复。
- 战机、BOSS 与背景均为程序化矢量绘制，与原作造型仍有差距；章节背景为静态离屏画布，无视差滚动。
- 暂无关卡评级与分解奖励。
- 未在真实手机上验证触屏手感与刘海安全区，仅完成 CSS 与桌面模拟检查。
- `file://` 下 `localStorage` 行为依赖浏览器策略（Chrome / Edge 正常）。
